## Featured Projects

### 🅿️ ParkVision — Parking Lot Occupancy Detector
**Course:** ITAI 1378 – Computer Vision & AI

Real-time parking space detection using a fine-tuned YOLOv8s model on overhead camera images. Each parking space is classified as **occupied** or **empty** with a visual bounding box overlay and live availability count.

| Metric | Result |
|---|---|
| mAP@0.5 | **99.5%** (target: 85%) |
| Precision | **99.8%** |
| Recall | **99.8%** |
| Inference Speed | **~17ms** (57× faster than target) |

**Stack:** YOLOv8s · PyTorch 2.0 · OpenCV · Google Colab T4 GPU · PKLot Dataset (~12K images)

📁 [View Project →](https://github.com/YusufShahz/ITAI1378_Midterm_ParkVision)

### 🗞️ NewsBot Intelligence System 2.0
**Course:** ITAI 2373 – Natural Language Processing

An end-to-end NLP pipeline that processes, classifies, and extracts structured intelligence from news articles at scale. Built across 7 integrated modules — from raw article input to full intelligence report output — processing 1,440 BBC News articles with 97.22% classification accuracy.

| Metric | Result |
|---|---|
| Classification Accuracy | **97.22%** (Linear SVM) |
| Articles Analyzed | **1,440** BBC News articles |
| Named Entities Extracted | **8,297** |
| Languages Supported | **55+** |
| Analyst Time Saved | **~92%** |

**Stack:** scikit-learn · spaCy · NLTK · pyLDAvis · langdetect · Google Colab

📁 [View Project →](https://github.com/YusufShahz/ITAI2373-NewsBot-Final)
